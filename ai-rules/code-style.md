# Code Style Rules

- Follow industry best practices and standards for the language in use.
- Variable names must be meaningful and descriptive of their purpose.
- Variable names must be at least 3 characters long. Single-letter and two-letter names are forbidden.
- Zero-doc clean code: code must be self-explanatory through naming and structure. Do not add comments or docstrings that merely restate what the code does.
- Files must not exceed 500 lines. If a file grows beyond this limit, refactor by splitting it into smaller, focused modules.
- Methods and functions must not exceed 200 lines. If a method grows beyond this limit, decompose it into smaller, single-purpose functions.
